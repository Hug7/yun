# 1 项目结构

- Status: accepted

## 1.1 项目框架

```text
.
|——common/             # 通用层，包含：公共方法；
|——docs/               # 技术文档，包含：adr、输入表结构、输出表结构、领域文档、算法文档等；
|——problem/            # 问题层(模型层)，包含：问题定义、约束等；
|——resources/          # 资源层，包含：输入表模版、输出表模版、测试用例等；
|——scenario/           # 场景层，包含：站点、订单、时间窗、车型等；
|——solver/             # 求解层(control层)，调动全局资源；
|——test/               # 测试层，本地测算入口、单元测试等
```
